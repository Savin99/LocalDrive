# LocalDrive

Личное хранилище важных файлов для iPhone. Рабочие файлы лежат только на устройстве; при желании в выбранной через «Файлы» папке сохраняется отдельная зашифрованная резервная копия.

## Что умеет

- **Чат по документам — главная вкладка.** Пишете «паспорт савина илья» — в ответ данные паспорта и сам файл. Поле копируется нажатием, номер закрыт маской до Face ID или кода iPhone. «Номер паспорта» даёт одно поле, «когда истекает загран» — срок с кнопкой «Напомнить», «справка о принятии статьи» — файл с найденным фрагментом. Если вопрос неоднозначный, под ответом появляются чипы для уточнения. Уточнения относятся к прошлому ответу: «а дата выдачи?», «адрес какой?». Всё считается на iPhone, без сети; переписка живёт в памяти до перезапуска приложения и на диск не пишется
- **Поиск внутри файлов**: текст PDF и фото распознаётся на iPhone (Vision), поиск понимает русские окончания — «справку» найдёт «справка». Поиск по названию и содержимому есть и во вкладке «Файлы»
- **Данные паспортов**: машиночитаемая строка паспорта РФ и загранпаспорта разбирается с проверкой контрольных цифр. Поле, которое распознано неуверенно, помечается «проверьте»: его можно сверить с фото, исправить или подтвердить
- **Папки** со своим именем, цветом и иконкой (16 иконок, 8 цветов). На карточке папки — коллаж из превью её последних файлов
- **Суперскрытые папки** не видны в сетке и «Недавних». Их временно показывает секретный знак, нарисованный одним движением в любом месте «Файлов»: по умолчанию буква Z, свой знак рисуют в **Настройках → Скрытые папки → Знак**. Если знак не получается — там же «Открыть по паролю». Уход приложения в фон снова их прячет
- **Сводка хранилища** на главном: сколько занято, кольцевая диаграмма по папкам в их цветах, лента недавно добавленного
- **Тёмная тема** — переключается вместе с системной настройкой телефона
- **Цвет папки как тема экрана**: внутри папки её оттенок подхватывают фон и кнопки
- **Два вида отображения** файлов — карточками и списком, выбор запоминается
- **Папки-ленты** как документ: текст правится прямо на странице, Enter открывает следующий абзац; фото складываются в ряды по своим пропорциям — три портрета или семь узких кадров, ряд всегда по ширине страницы; фото перетаскиваются между рядами, блоки переставляются в режиме выделения; тап открывает полноэкранный просмотр со свайпом по всем вложениям документа — фото, видео, PDF и текст идут одной цепочкой в порядке страницы, панель со счётчиком, именем, стрелками и «Поделиться» не меняется при листании
- **Разметка в тексте ленты**: заголовки `#`, `##`, `###`, `**жирный**`, `*курсив*`, маркированные и нумерованные списки. Вне фокуса блок показывает готовый вид, по тапу — исходник со служебными символами; над клавиатурой панель с кнопками жирного, курсива, заголовков и списков — они работают и по выделению, и по строке под кареткой
- **Настоящие превью**: фото показывается фотографией, PDF и документы — первой страницей, текстовые файлы — первыми строками. Для форматов без превью — иконка по типу
- **Добавление** документов из «Файлов» и фото/видео из галереи (до 20 за раз)
- **Просмотр** любого файла системным QuickLook, «Поделиться» через стандартный лист
- **Переименование, удаление** (с подтверждением), **поиск** по имени внутри папки. У каждой папки есть переключатель «Доступна для поиска»
- **Защита**: кода на входе нет — приложение открывается сразу (решение владельца от 24.10.2026), приватное прячут суперскрытые папки. Шторка приватности в переключателе приложений, номер документа в чате — после Face ID или кода iPhone
- **Восстановление после потери iPhone**: автоматическая зашифрованная копия в выбранной папке iCloud Drive, до трёх версий и отдельный код восстановления
- **Анимации**: разворот карточки папки в экран (zoom-переход), пружинное появление карточек

Минимальная версия — iOS 26 (решение владельца от 12.10.2026). Пакеты MLX для модели чата используют `Span`, и при цели ниже iOS 26 Xcode кладёт в приложение библиотеку совместимости `libswiftCompatibilitySpan.dylib`. Подпись в IPA Shelf такую отдельную библиотеку не принимала. Модели к тому же нужен iPhone с 8 ГБ памяти, а такие все на iOS 26 и новее.

## Как это защищено

- Знак и пароль скрытых папок лежат в Keychain с `WhenUnlockedThisDeviceOnly` — не уезжают в iCloud и в резервные копии. Пароль не хранится нигде: только случайная соль и PBKDF2-HMAC-SHA256 на 600 000 раундов, проверка сравнивает за постоянное время. Ни пароль, ни точки знака не пишутся в журнал. Сменить знак или вернуть Z можно только с текущим паролем, иначе любой, кто взял телефон, нарисовал бы свой знак
- Хеш кода входа из прежних версий стирается при первом запуске: четыре цифры перебираются мгновенно, а код мог совпадать с другими
- Файлы лежат в `Application Support/Vault/<UUID папки>/` с `FileProtectionType.complete` — на заблокированном устройстве они зашифрованы и недоступны даже самой системе
- Резервная копия шифруется AES-GCM на устройстве порциями по 1 МиБ; имена файлов находятся внутри зашифрованного манифеста
- 256-битный ключ восстановления хранится в Keychain с `WhenPasscodeSetThisDeviceOnly` и не переносится на новый iPhone. Для восстановления нужен показанный приложением код — без него копию не расшифровать
- При копировании код попадает только в локальный буфер обмена и получает срок жизни 5 минут. Его нужно отдельно сохранить в менеджере паролей или распечатать
- Индекс поиска (распознанный текст и поля документов) лежит в `Application Support/SearchIndex/` с той же защитой `.complete`, исключён из резервных копий iOS и в зашифрованную копию не попадает — после восстановления он строится заново. Удалённое затирается: `secure_delete` и слияние сегментов FTS5
- Суперскрытые папки не индексируются вообще: чат и поиск не знают ни их файлов, ни их количества. Когда папку скрывают, всё извлечённое из неё стирается сразу
- Поля из чата копируются только в локальный буфер на 2 минуты, номер документа — после Face ID или кода iPhone. Модель в чате (если её скачать) не видит ни текста документов, ни значений полей
- **Облачное распознавание выключено по умолчанию.** Если его включить в **Настройках → Модели на iPhone → Облачное распознавание**, фото и сканы документов уходят в OpenAI (по умолчанию) или в Google Gemini по вашему ключу:
  - только из папок, доступных для поиска, — суперскрытые и убранные из поиска не отправляются никогда;
  - в запросе только кадр страницы и инструкция, без имён файлов и папок;
  - PDF с текстовым слоем не отправляются;
  - ключ хранится в Keychain «только на этом устройстве», у каждого сервиса свой;
  - OpenAI: ответы не хранятся (`store=false`), на данных API модели не обучаются, журналы проверки на злоупотребления — до 30 дней;
  - из России ни OpenAI, ни Gemini не работают без VPN; по правилам OpenAI доступ из неподдерживаемой страны может привести к блокировке аккаунта;
  - у Gemini нужен платный ключ: на бесплатном Google читает данные и обучается на них.

  Подробности и цены — в [docs/cloud-reader.md](docs/cloud-reader.md)

Ограничение, о котором стоит знать: суперскрытые папки спрятаны, а не зашифрованы отдельно. Кто держит разблокированный iPhone, видит остальные папки и чат, знак можно подсмотреть через плечо, а пароль от четырёх символов защищает от случайного взгляда, не от перебора. Настоящая защита данных здесь — шифрование файловой системы iOS, привязанное к паскоду телефона.

## Модели на iPhone

Обе модели необязательные и скачиваются по кнопке в **Настройках → Модели на iPhone**. Это единственный выход приложения в сеть; дальше модели работают на iPhone через MLX. В памяти всегда одна: перед загрузкой одна выгружает другую.

### Модель для чата

Без модели чат отвечает правилами: понимает «мой паспорт», «номер паспорта», «когда истекает загран» и поиск по тексту. Свободные вопросы и уточнения вроде «а загран?» понимает локальная модель Qwen3 4B (`mlx-community/Qwen3-4B-Instruct-2507-4bit`, ревизия закреплена), около 2,2 ГБ.

- Модель не видит ни текста документов, ни значений полей. Ей достаются вопрос, список видов документов и прошлые вопросы с планами ответов. Она возвращает только план — тип документа, нужные поля, поиск. Генерация ограничена грамматикой: в собственном ответе модели не может быть цифр. Карточки, как и без модели, заполняет приложение из своей базы
- Если модель не ответила за 20 секунд, ошиблась или увела вопрос о документе в разговор — отвечают правила
- Нужно около 3 ГБ свободной памяти, поэтому подходят iPhone с 8 ГБ. Повышенный лимит памяти не запрошен: такой entitlement мешал бы подписи IPA присланным профилем. Если памяти мало, настройки об этом скажут, а чат продолжит отвечать правилами
- В симуляторе MLX не работает: там чат всегда отвечает правилами
- Замеры и выбор модели — в [docs/llm-ondevice.md](docs/llm-ondevice.md)

### Чат через облако

Переключатель «Чат через облако» на экране облачного распознавания, выключен по умолчанию, нужен ключ выбранного сервиса. Тогда в чате отвечает GPT-6 Luna, GPT-6.1 Sol или GPT-6 Astra (у Gemini — 3.8 Flash или 3.5 Flash-Lite) — выбор чипом на поле ввода, там же чип рассуждения (Авто, Быстро, Подумать).

- Однозначный поиск своего документа («паспорт ильи») правила отвечают сразу, без облака; «Подумать» — всегда облако.
- Пока облако думает — строка «Думает · N с», на месте «Отправить» — «Стоп». Если облако молчит 20 с или отвечает дольше 60 с, отвечают правила с пометкой о причине.

- Модель сама ищет документы и папки инструментами на iPhone и показывает те же карточки: значения подставляет база.
- Серию, номер и номера договоров модель видит только маской, в её тексте они закрываются.
- Суперскрытые папки для неё не существуют. Переписка — только в памяти.
- Действия с файлами модель только предлагает: ничего не меняется без «Выполнить».
- Без связи или при ошибке отвечают правила на iPhone с пометкой: «проверьте VPN», «Ключ не подошёл», «думало дольше N с».
- Подробности — в [docs/cloud-chat.md](docs/cloud-chat.md).

### Модель для документов

Модель «текст + картинка» второй раз читает фото паспорта или прав, если распознавание текста не подтвердило ФИО, номер или даты. Моделей две, ревизии закреплены:
- Qwen3.5 4B (`mlx-community/Qwen3.5-4B-4bit`), около 3 ГБ, нужно 4 ГБ свободной памяти;
- облегчённая Qwen3.5 2B (`mlx-community/Qwen3.5-2B-4bit`), 1,75 ГБ, нужно около 2,8 ГБ. На iPhone 16 Pro Max приложению доступно 3,24 ГБ — подходит эта.

Экран модели советует ту, что помещается в память, и показывает, сколько удостоверений прочитано и сколько ждут. Пока идёт работа, над полем ввода в чате видно «Распознаю документы…» или «Модель перечитывает документы…».

- Читает только удостоверения из папок, доступных для поиска, и только пока приложение на экране; сначала распознаётся всё новое
- Проверенное контрольными цифрами MRZ и исправленное вручную не меняет. Её значение помечено «проверьте», если его нет в распознанном тексте той же страницы
- Если памяти не хватает ни одной — документы разбираются без модели, экран модели говорит почему
- Замер на синтетических паспортах и устройство — в [docs/doc-reader.md](docs/doc-reader.md)

## Порядок файлов в папке

В меню вида (иконка сетки в правом верхнем углу папки) есть сортировка: по дате добавления, по дате самого файла, по имени, по размеру и вручную. Выбор запоминается для каждой папки отдельно и хранится в `vault.json`.

Дату самого файла — когда снято фото или записано видео — приложение берёт из EXIF или метаданных видео. Импорт документа сохраняет дату исходника при копировании, а для фото из галереи дата дозаполняется в фоне при первом открытии папки и складывается в `.dates.json` рядом с файлами.

Кнопка со стрелками включает режим перестановки — туда же ведёт пункт «Переставить файлы» в меню файла и выбор сортировки «Вручную». В этом режиме у карточек появляется «ручка», файл зажимается и перетаскивается: пока палец над чужой карточкой, у неё подсвечивается край — файл встанет именно на её место. Смена цели отдаёт лёгким тиком, постановка — слабым толчком. Порядок пишется в `.order.json` внутри самой папки, поэтому переживает перезапуск приложения и попадает в резервную копию. Файлы, добавленные после перестановки, встают в конец. Перетаскивание живёт в отдельном режиме не случайно: в SwiftUI `contextMenu` и `draggable` на одном вью не уживаются — меню забирает долгое нажатие.

## Установка на свой iPhone

Проект генерируется из `project.yml` через [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
xcodegen generate
```

Дальше:

1. Открыть `LocalDrive.xcodeproj` в Xcode
2. Подключить iPhone кабелем и выбрать его как устройство сборки
3. Нажать ⌘R

Для резервных копий отдельная iCloud capability не нужна. При первой настройке LocalDrive открывает системное приложение «Файлы»: выберите или создайте папку в iCloud Drive. Приложение сохраняет security-scoped bookmark, поэтому после этого может обновлять зашифрованные копии в выбранной папке автоматически. Если доступ будет отозван в настройках iOS или приложение установлено на новый iPhone, папку нужно выбрать заново.

Если выбор папки недоступен — например, приложение переподписано инструментом, который меняет ему bundle id, и iOS отказывается выдавать доступ к папке, — копию можно передать без всякого выбора. Откройте «Файлы» → «На iPhone» → **LocalDrive** и положите туда папку `LocalDrive Backups` целиком либо одну нужную версию `backup-….ldbackup`. Это собственная папка приложения, доступ к ней не зависит от подписи: LocalDrive найдёт копию сам, останется ввести код восстановления. Ваши файлы при этом наружу не видны — хранилище лежит в `Library/Application Support`, а в «Файлах» открыта только `Documents`.

На новом iPhone откройте **Настройки → Восстановить из копии**, выберите ту же папку в iCloud Drive и введите сохранённый код восстановления. Имена и содержимое файлов находятся внутри AES-GCM-зашифрованного пакета; снаружи видны только папки версий и технический `info.json` с датой, размером и версией схемы.

Подпись — автоматическая, но Team ID в репозитории не лежит. Выберите свою команду в Xcode: таргет **LocalDrive → Signing & Capabilities → Team**. Чтобы не выбирать её заново после каждого `xcodegen generate`, положите ID один раз в `Support/Signing.local.xcconfig` (этот файл в `.gitignore`):

```
DEVELOPMENT_TEAM = ABCDE12345
```

Если Xcode попросит, разрешите доступ к Keychain и на самом iPhone подтвердите доверие профилю разработчика: **Настройки → Основные → VPN и управление устройством**.

При сборке через Apple ID без платного аккаунта разработчика приложение живёт на устройстве 7 дней, потом нужно пересобрать.

## Сборка .ipa для подписи своим сертификатом

```bash
tools/release-ipa.sh
```

Команда собирает Release arm64 без подписи, сохраняет локальную IPA в `build/dist/` и атомарно публикует её в общей папке iCloud Drive → **IPA Shelf**. Bundle ID остаётся `com.ilyaqa.LocalDrive`. Для локальной сборки без iCloud добавьте `--no-cloud`. Правила выпуска и публикация уже готового IPA — [IPA_RELEASE.md](IPA_RELEASE.md).

Подписывающий инструмент должен сохранить в Info.plist все описания доступа — `NSFaceIDUsageDescription`, `NSPhotoLibraryUsageDescription` и `NSRemindersFullAccessUsageDescription`, иначе Face ID, выбор фото и кнопка «Напомнить» в чате будут падать при первом обращении.

Если после переподписи Keychain окажется без нужного entitlement, `SecretStore` сам переключится на файлы `hidden-symbol.dat` и `hidden-password.dat` в контейнере приложения с `FileProtectionType.complete`, исключённые из резервных копий iPhone, — знак и пароль скрытых папок всё равно сохранятся между запусками. `NSFaceIDUsageDescription` по-прежнему нужен: Face ID подтверждает показ номера документа в чате.

## Иконка

Текущая иконка — абстрактный куб из слоёв на тёмном индиго, вариант `v7` из [Design/icon-variants/](Design/icon-variants/). Там же лежат все 13 сгенерированных вариантов и общий лист `_all.png`.

Иконки сгенерированы через Higgsfield CLI, моделью `recraft_v4_1`:

```bash
higgsfield generate create recraft_v4_1 --prompt "<описание>" \
  --aspect-ratio 1:1 --resolution 1k --model-type standard --wait
```

Модель рисует скруглённый квадрат со светлыми уголками, а iOS маскирует иконку сам — поэтому перед установкой картинку надо прогнать через [Design/finalize_icon.py](Design/finalize_icon.py), он растягивает внутреннюю часть на весь квадрат и проверяет, что светлых уголков не осталось:

```bash
python3 Design/finalize_icon.py Design/icon-variants/v7.png \
  Sources/Assets.xcassets/AppIcon.appiconset/icon-1024.png
```

Чтобы поставить другой вариант — подставьте его номер в команду выше и пересоберите.

Метаданные папок — в `Vault/vault.json`, список файлов всегда читается прямо из файловой системы. Для поиска и чата текст файлов распознаётся в отдельный индекс; как он устроен и что проверено замерами — в [docs/search.md](docs/search.md), про локальную модель — в [docs/llm-ondevice.md](docs/llm-ondevice.md), про действия с файлами — в [docs/files.md](docs/files.md), про переключение «Чат | Файлы» — в [docs/navigation.md](docs/navigation.md).

Лента папки лежит в скрытом `Vault/<UUID>/.feed.json`: блоки плюс пропорции медиа отдельным словарём — так они переживают объединение рядов, разделение и перенос фото. Файлы старого формата (просто массив блоков) читаются как есть, пропорции досчитываются при первом открытии.

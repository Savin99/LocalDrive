# Карточки фактов

Просьба владельца от 24.10.2026: место для того, что он просит запомнить, но
чего нет ни в одном документе, — где живёт Камила: код домофона, адрес, этаж.
Поля гибкие, их заводит агент чата сам, со значками; адрес и ссылка — не текст,
а кнопка. Потом на «дом Камилы» чат отвечает домофоном, этажом и адресом.

Здесь — модель, хранение, вид карточки, страница и редактор. Создание карточки
из чата и третья страница переключателя подключаются отдельно.

## Что есть

- **Модель** — `Sources/Facts/FactCard.swift`. `FactCard`: название, значок
  SF Symbols, цвет из палитры папок, поля, даты создания и изменения.
  `FactItem`: вид (адрес, ссылка, телефон, e-mail, код, текст, дата, число,
  Wi-Fi, заметка), подпись, значение, необязательный значок.
- **Хранилище** — `Sources/Facts/FactStore.swift`, `@MainActor @Observable`.
  Один файл `facts.json` в корне хранилища рядом с `vault.json`, формат
  `{"version": 1, "cards": [...]}`. Карточки — сначала недавно изменённые.
- **Карточка** — `Sources/Views/Facts/FactCardView.swift`. Без своей навигации:
  живёт и на странице, и в ответе чата. `highlighted` подсвечивает поля, о
  которых спросили.
- **Страница** — `FactsView`: поиск, карточки одной колонкой целиком, шапка
  карточки открывает её экран (`FactDetailView`: правка, «Поделиться»,
  удаление), «+» — редактор. Пустое состояние подсказывает, что сказать чату.
- **Редактор** — `FactEditorView(card:onSave:)`. Хранилище не трогает: отдаёт
  готовую карточку в `onSave`. `card == nil` — новая; карточка, которой ещё нет
  в хранилище, — черновик от чата, id сохраняется.

## Решения

- **Одна колонка целых карточек, а не сетка плиток.** Смысл страницы — быстро
  достать домофон: строки нажимаются прямо в списке, без перехода внутрь.
- **Касание поля делает главное действие.** Адрес — Карты, ссылка — браузер,
  телефон — звонок, почта — письмо; справа у них цветная круглая кнопка. Код,
  Wi-Fi, число, текст, дата и заметка копируются, справа серый значок
  копирования, как у полей документа в чате. Долгое нажатие — «Скопировать»,
  «Открыть…», «Поделиться». Если строку не удалось превратить в ссылку
  («позвоню позже» в поле телефона), касание её копирует.
- **Буфер** — только этого iPhone и на две минуты (`localOnly`,
  `expirationDate`), как у копирования из чата. Тактильный отклик и галочка —
  те же.
- **Карты — «единые ссылки» Apple** (iOS 18.4+, у приложения iOS 26):
  `https://maps.apple.com/search?query=<адрес>`, для точки «55.7558, 37.6173» —
  `/place?coordinate=`. Адрес кодируется только незарезервированными символами
  RFC 3986: «&», «+», «#» не рвут параметр.
- **Ссылка без схемы** получает `https://`. `javascript:`, `file:`, `data:`,
  `vbscript:` не открываются никогда; http(s) без точки в имени сервера —
  тоже не ссылка.
- **Значок поля**: выбранный агентом, если он есть в системе
  (`UIImage(systemName:)`), → по подписи («Домофон», «Код домофона» → звонок,
  «Этаж» → лестница, «Подъезд», «Квартира», «Пароль», «Wi-Fi»…) → по виду.
  Порядок правил важен: «Пароль Wi-Fi» — сеть, «Городской телефон» — телефон.
  Новая карточка сама берёт значок по названию: «Дом Камилы» → домик.
- **Незнакомый вид поля** (от агента или будущей версии) читается как текст;
  отсутствующие поля — значениями по умолчанию. Испорченный `facts.json` не
  затирается, а откладывается рядом как `facts.damaged-<время>.json`.
- **Файл закрыт до разблокировки.** Если `facts.json` есть, но не читается
  (запуск в фоне на заблокированном iPhone), запись в него не идёт, пока
  чтение не удастся: иначе пустой список затёр бы карточки. Повторное чтение —
  при любом изменении и по `protectedDataDidBecomeAvailableNotification`.
- **В журнал не пишутся значения** — только число карточек и тип ошибки.

## Поиск

`FactStore.search(_:)` и `matches(_:)` (с подсвечиваемыми полями),
логика — `Sources/Facts/FactSearch.swift`. Карточек десятки, поэтому без
индекса, перебором.

- Слова режутся и приводятся к основе так же, как в поиске по документам
  (`SearchText`, Snowball); служебные слова — тот же список `SearchQuery.stopWords`
  плюс просьбы вокруг вопроса («скажи», «напомни», «пожалуйста»).
- **Snowball режет имена неровно** (замер тестом): «Камила» для него глагол на
  «-ила» с основой «кам», а «Камилы» — «камил». Поэтому слова с общим началом
  от четырёх букв, у которых различаются только последние две, тоже
  совпадают: «Камила», «Камилы», «Камилин». «Петра» и «Петя» — нет.
- Слова двух сортов. **Общие** называют поле — домофон, этаж, адрес, живёт,
  пароль: они выбирают, какое поле подсветить. **Особые** — остальное, обычно
  имя. Карточка подходит, если в ней есть все особые слова, — «дом Петра» не
  покажет «Дом Камилы» по слову «дом». Если спросили о поле, карточка должна
  его объяснить: на «домофон Камилы» не придёт «Дача», где Камила только в
  значении «ключи у Камилы».
- Вес: название 8, подпись поля 4, вид поля 3, значение 2. Слово из названия
  выбирает карточку целиком («дом Камилы» — без подсветки), остальные
  подсвечивают поля. Вид находит поле и без подписи: «где живёт Камила» →
  поле вида «адрес».
- Если ни одна карточка не содержит всех особых слов, а их два и больше,
  хватает одного: лишнее «срочно» не обнуляет выдачу.

## Резервная копия и восстановление

`facts.json` лежит в `Vault/`, поэтому зашифрованная копия берёт его сама —
проверено тестом `testEncryptedBackupRoundTripsFacts` через
`EncryptedBackupEngine`: карточка удалена после копии и вернулась после
восстановления.

Восстановление заменяет папку целиком. `BackupManager.restore` после успешной
замены шлёт `Notification.Name.vaultDidRestore`, `FactStore` перечитывает файл
сам — экрану восстановления о карточках знать не нужно. Вручную — `reload()`.

## Проверено

Симулятор iPhone 17 Pro, iOS 26.5, 24.10.2026, модульные тесты: карточек
касаются 47 (12 + 11 + 15 + 9, один пропущен — см. ниже), весь
`LocalDriveTests` — 480 тестов без падений.

- `FactStoreTests` — изменения, порядок, счётчик `revision`, перезапуск без
  потерь до миллисекунды, перечитывание, уведомление о восстановлении,
  испорченный файл, незнакомый вид поля, круг «копия → удаление →
  восстановление».
- `FactSearchTests` — «дом Камилы», «Камила», «домофон Камилы», «где живёт
  Камила», «Камилин дом», подсветка полей, стоп-слова, порядок «название выше
  поля», «дом Петра» → пусто.
- `FactLinksTests` — ссылки Карт, `tel:`, `mailto:`, ссылки без схемы и
  опасные схемы, кириллический домен, значки по подписи и по виду, и что
  каждый значок из кода есть в SF Symbols этой iOS.
- `FactsScreenshotTests` — снимки страницы, экрана карточки и редактора в
  светлой и тёмной теме, пустого состояния и подсвеченной карточки в
  `build/shots/`. Ничего не сравнивают: глазами.

Замер: `ImageRenderer` не рисует `NavigationStack` и `ScrollView`, поэтому
экраны снимаются из настоящего окна (`drawHierarchy`). Асинхронный тест,
закрывавший окно посреди ожидания, падал ошибкой SwiftUI «InvalidTransition»;
синхронный с окнами до конца теста — нет.

## Не проверено

- **Класс защиты файла.** Симулятор не сообщает `protectionKey` даже у файла,
  записанного с `.completeFileProtection` (замер), поэтому тест в нём
  пропускается. На iPhone не проверено.
- Что ссылки Карт открывают именно приложение «Карты», а `tel:` и `mailto:` —
  звонок и письмо: в модульном тесте проверена только сама ссылка.
- Отправка `vaultDidRestore` из `BackupManager.restore` — тест шлёт
  уведомление сам: настоящее восстановление пишет ключ в Keychain.
- Касания, меню и «Поделиться» на устройстве и с VoiceOver; UI-тестов нет —
  страница ещё не встроена в переключатель.
- Как выглядит длинная карточка (20+ полей) и очень длинные значения.

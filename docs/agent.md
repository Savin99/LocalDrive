# Агент в чате — облако и iPhone

Решение владельца 24.10.2026: «нормального агента в чате, а не ограниченный
план». Выбор: **один агент с одними инструментами** — есть ключ и связь, думает
облако (OpenAI или Gemini), нет — модель на iPhone; изменения агент только
**предлагает**, выполняет человек кнопкой.

## Как отвечает чат

```
вопрос ─► правила (мгновенно): владелец, «положи в …», «в фамилии ошибка»,
          вложение, «дата рождения Ольги», «дом Камилы», уточнения
          └─ точный ответ ─► сразу
          └─ иначе ─► облако (CloudChatEngine)       — есть ключ и связь
                    └► агент на iPhone (LocalAgentEngine) — модель скачана
                    └► ответ правил                     — иначе или по сбою
```

- **Инструменты общие** — `CloudChatTools`: поиск, документ, папки, файлы,
  сроки, карточки ответа, предложения перенести файлы, «Карточки», исправление
  поля. Номера уходят модели маской, MRZ вырезается, файлы и поля меняются
  только предложением.
- **Шаги** обоих агентов — в ленте чата (`CloudChatSteps`): «Ищу в
  документах: «…»», «Открываю: Паспорт РФ — …», «Готовлю исправление: «ФИО»».

## Агент на iPhone

Прежде модель возвращала один «план» из четырёх действий (`ChatPlan`,
грамматика EBNF). Теперь — настоящий цикл (`LocalAgentEngine`):

- Qwen3-4B-Instruct-2507 через `MLXLMCommon.ChatSession` с инструментами в
  формате Qwen (`<tool_call>`): модель сама зовёт инструменты, результаты
  возвращаются ей репликой `tool`, до 5 шагов.
- **Одна сессия на разговор** (`LocalChatModel.beginAgent`): кэш промпта живёт
  между шагами и между вопросами — инструкция, инструменты и опись
  разбираются один раз. Реплики, на которые ответили правила, дописываются
  перед новым вопросом. «Новый чат» и смена описи — новая сессия.
- **Короткие инструменты** (`LocalAgentPrompt.toolsJSON`): те же имена и
  аргументы, что у облака, описания короче и без редких полей; без страниц
  картинками — модель текстовая. Описания облака на русском занимали больше
  2000 токенов.
- **Опись с подписями**: «d21 — Паспорт РФ; владелец: Трошина О. П.; папка:
  Ольга». Без подписей модель путала колонки.
- **Подстраховки**: вызов, написанный словами («search_documents(query=…)»),
  исполняется, если имя инструмента объявлено, а в ответе больше ничего нет;
  оборванный или кривой вызов — модель получает ошибку и повторяет один раз;
  номера, прошедшие через инструменты, в тексте закрываются маской.
- Срок — 45 с на вопрос, затем ответ правил («Модель не успела — отвечаю по
  базе»). Пока человек переписывается, модель документов не вытесняет модель
  чата (`ModelResidency`).

## Стенд на Mac — 24.10.2026

`scratchpad/agent-bench` этой сессии: та же модель (ревизия `50d42775…`), та
же инструкция и инструменты — `LocalAgentPromptTests` выгружает их в
`fixtures/`, синтетическое хранилище по образцу владельца (паспорта трёх людей,
развороты, загранпаспорт, свидетельство о браке, договор, полис, справка,
«Входящие», карточки «Дом Камилы» и «Дача»). 13 вопросов, которых правила не
закрывают: «в какой папке паспорт Ольги», «перенеси договор аренды в папку
Квартира», «какие документы скоро истекают», «сколько у меня паспортов и
чьи», «все данные паспорта Ильи», «запомни: Wi-Fi…», «код домофона у Камилы»,
«найди справку с работы», «в паспорте Ольги ошибка в фамилии», «привет»,
«разложи файлы из Входящих», «где свидетельство о браке», «что есть на
Ольгу». Apple M4, генерация жадная.

| Вариант | Успешно | Медиана | p90 |
| --- | --- | --- | --- |
| Описания облака, новая сессия на вопрос | 7/12 | 9,8 с | 15,0 с |
| Короткие инструменты, новая сессия | 7/12 | 7,0 с | 9,3 с |
| Короткие инструменты, одна сессия | 8/12 | 2,5 с | 6,0 с |
| + опись с подписями, 2 прохода | 17/26 | 1,9 с | 3,2 с |
| + перенос по id документа, 2 прохода | 21/26 | 2,1 с | 9,6 с |

Оставшиеся промахи: «запомни» с двумя значениями (одно поле вместо двух — в
приложении «запомни» без облака разбирают правила), ложное «исправлено» без
вызова (в приложении эту фразу перехватывают правила; в инструкции запрет),
повторы кривого вызова при раскладывании «Входящих» (теперь повтор один).

Тот же стенд нашёл утечку: выдержка поиска — одна строка, построчный фильтр
MRZ её пропускал, и номер паспорта уходил модели — и облачной тоже. Теперь
MRZ вырезается и по словам (`CloudChatTools.looksLikeMRZFragment`), тест —
`ChatAgentTests.testAgentCallsToolsInStepsAndShowsCards`.

## Живая проверка на OpenAI — 24.10.2026

`GenUILiveEvalTests.testOwnerScenariosOnRealModel`, 3 прогона. Шаги A и C —
путь приложения (правила первыми): все 3/3, ответ мгновенный. Шаги B — само
облако, правила выключены: B1–B3 3/3 (в одном из повторов B3 — 2/3, пустой
ответ), B4 «в фамилии ошибка, правильно Трошкина» после «паспорт Ольги» —
2/3. Модель присылала ФИО то с инициалами из описи («Трошкина О. П.»), то
без отчества («Ольга Трошкина»); теперь правка ложится на текущее ФИО
(`ChatFieldFix.correctedName`): инициалы раскрываются, одно новое слово
заменяет самое похожее. Оставшийся промах — модель переспросила фамилию; в
приложении эту фразу закрывают правила раньше облака.

## Не проверено

- **Время на iPhone.** На M4 медиана 2,1 с в одном разговоре; iPhone 16 Pro
  Max, по прежним замерам, в 2–3 раза медленнее, а первый вопрос разговора
  разбирает инструкцию целиком.
- **Память**: кэш промпта растёт с разговором; пик на iPhone не мерен.
- Перенос по `document_id` облачным агентом проверен тестами с заглушкой
  сети; живьём — только перенос правилами (шаг C5).
